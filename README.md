# 守护侠（ShouHuXia）

给独居长辈手机用的"无活动守护" Android 应用：手机长时间没人用，先大声响铃请对方确认；仍然无人响应，先给 1–3 位紧急联系人群发紧急短信，再按顺序依次拨打电话。

- 包名：`com.jiarenxia.guardian`（debug 包加 `.debug` 后缀）
- 系统要求：Android 8.0（API 26）及以上
- 不联网：拨号和短信走运营商网络，只联系你设定的紧急联系人

---

## 工作原理

```text
解锁使用中 ──► 不计时
    │ 锁屏
    ▼
从锁屏时刻开始倒计时（默认 8 小时，可选 1–24 小时）
    │ 到点仍没人用过手机
    ▼
大声响铃 + 锁屏上弹出全屏确认页（默认等 2 分钟）
    │                                │
    │ 点"我没事"或解锁                 │ 无人响应
    ▼                                ▼
重新计时                        先给所有紧急联系人群发紧急短信，
                                再按顺序依次拨打：每通查通话记录
                                判定是否接通；有人接通即停（默认）
                                或拨完所有人；一轮无人接 3 分钟
                                后再拨一轮，最多 2 轮，最后群发
                                结果短信（谁接了 / 无人接听）
```

- 接打电话、解锁都算"有人在用"；来消息亮屏、未接来电不算。
- 任一阶段解锁或点"我没事"即解除：停止拨号，群发"已解除"短信。
- 可设夜间免打扰时段：时段内到点的报警顺延到时段结束。
- 每日平安短信（可选）：每天给所有紧急联系人发一条近况。家人每天收到它，就说明守护在正常工作；哪天没收到，就该打电话问问。

## 在长辈手机上设置

守护侠的定位是**设置一次、之后不用管**，所以第一次设置要求比较严格。首页就是四步向导，主按钮始终指向下一步：

1. **紧急联系人**：从系统通讯录选择或手动输入，可设 1–3 位并调整顺序——顺序就是拨打顺序。另有「有人接通后」策略：接通即停（默认）或拨完所有人。
2. **权限与系统设置**：发送短信、读取通话记录、拨号、电话状态、通知均为必需项；能检测的项自动检测；检测不到的项（自启动、省电策略"无限制"、多任务锁定等）逐项跳到系统页面设置，再手动勾选确认。
3. **实机演练**：锁屏放着别动，到点会真实响铃、弹出测试页，然后给每位联系人发一条测试短信并依次拨打（对方需要接听），最后回到 App 逐位确认。等待时长 1 分钟 / 10 分钟 / 30 分钟 / 1 小时 / 2 小时可选，**等待 ≥ 30 分钟且全部检查项通过才算数**。
4. **开启守护**：前三步都完成后才能开启。

之后增删联系人、改号码、调整顺序、升级 App 或系统升级，演练记录都会失效。守护会继续运行，但首页会提示需要重新测试。演练随时可以重做。

> 演练会真实拨号。请先告知紧急联系人，测试时不要拿真实家人号码反复回归。

## 局限性

- 手机没电、欠费、取出 SIM 卡、开飞行模式时无法报警。
- 设置了 SIM 卡 PIN 码的手机，重启后要先输入 PIN 才能拨号，建议去掉 SIM PIN。
- 报警最多拨 2 轮；无法往通话里放语音，情况说明靠紧急短信。通话记录写入有延迟、个别 ROM 号码格式差异，判定失败会按未接通多打。
- 在系统设置里"强行停止"应用后，守护会停止，直到重新打开应用（这是 Android 的规定行为）。
- 被守护的手机必须设置锁屏（上滑、图案、密码、指纹、人脸均可），否则"解锁"信号不可靠。

## 隐私

- 配置与状态只保存在本机的设备加密存储区，不参与系统云备份和设备间迁移，换机后需要重新设置。
- 日志里的手机号一律打码。
- 选择紧急联系人用的是系统联系人选择器，只读取选中的那一个号码。
- 通话记录只在报警/演练期间查询，且只查守护侠自己拨出的那几通（拨号时刻之后、号码在紧急联系人列表中）；只在内存中比对是否接通，不读取其他记录、不保存通话记录内容。
- 短信只发给紧急联系人（紧急 / 结果 / 已解除 / 测试 / 平安短信）；平安短信的内容是最后一次使用手机的时间、电量和是否在充电。

## 开发

### 模块

| 模块 | 说明 |
|---|---|
| `:guardianapp` | 应用模块 |
| `:feature:guardian` | 守护模块：引擎、实机演练、权限检测、界面（不依赖 Hilt / Room） |
| `:core:designsystem` | 主题与通用组件 |

### 构建与测试

需要 JDK 17 和 Android SDK；在 `local.properties` 写好 `sdk.dir`（用正斜杠，例如 `sdk.dir=D:/AndroidDev/sdk`）。Gradle 根目录就是仓库根目录，完整验证任务：

```
gradlew :feature:guardian:testDebugUnitTest :guardianapp:testDebugUnitTest :guardianapp:lintDebug :guardianapp:assembleDebug :guardianapp:assembleRelease
```

APK 输出在 `guardianapp/build/outputs/apk/`。各开发机的路径、代理和调用方式见 `AGENTS.md`。

### 正式版签名

工程根目录放 `keystore.properties` 与签名文件（均已被 `.gitignore` 忽略）。缺少签名文件时 release 包保持未签名，不会回落到 debug 签名。
