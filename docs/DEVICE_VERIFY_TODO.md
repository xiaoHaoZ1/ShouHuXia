# 真机待验证清单

> 由用户本人在真机上执行（见 `AGENTS.md`「测试分工」）。完成一项勾一项；不符合预期时按「记录」一栏留证据，反馈给模型定位。
> 对应代码：提交 b11633e … 13d8e48（开启向导 + 实机演练 + 两轮修复）。
> F 节对应提交 caf8626 … f0f41d6（多位紧急联系人 + 轮流重拨 + 报警短信）。

## 准备

- 测试机：Redmi K70 至尊版（Android 14）。有 Android 12 或更低版本的手机更好（见 E1）。
- 安装 debug 包：`<SDK>\platform-tools\adb.exe -s <真机序列号> install -r guardianapp/build/outputs/apk/debug/guardianapp-debug.apk`。全新安装的场景（B1）需要先卸载。
- 紧急联系人只用**安全号码**（自己的另一部手机，或事先告知的人），**不得**用真实家人号码。
- 通用记录方式：截图 + 守护记录页（事件日志）里的相关几行 + 演练结果卡逐项的 ✓/✗。

---

## A. 最关键：演练能不能抓到真实故障（优先做）

- [ ] **A1 后台被清理 → 判"未通过"而不是"中止"**
  - 操作：在系统设置里把守护侠的省电策略改回"智能 / 默认"（不要选"无限制"），也可以同时关掉自启动。做一次 30 分钟演练，锁屏放着；中途可以在最近任务里把守护侠划掉。到点后解锁，打开 App。
  - 预期：结果为"未通过"，原因类似"到点没有响铃 / 锁屏期间守护未能按时响铃，请检查省电策略、自启动、多任务锁定"。**绝不能是"中止"**。
  - 记录：结果卡截图、事件日志。做完记得把省电策略改回"无限制"。

- [ ] **A2 响铃时强行停止 → 之后打开不会突然拨号**
  - 操作：开始一次 1 分钟演练，到点响铃、弹出测试页时，进 设置 → 应用信息 → 守护侠 → 强行停止。等 2 分钟以上再打开 App。
  - 预期：**不拨号**；结果为"未通过：确认窗口结束后没有自动拨号"。
  - 记录：有没有拨号；结果卡截图。

- [ ] **A3 正确设置后，30 分钟演练通过**
  - 操作：权限清单全部完成（省电"无限制"、自启动、多任务锁定等），做一次 30 分钟演练：锁屏放着 → 到点响铃 → 锁屏上弹出"这是守护测试" → 不要操作，等自动拨号 → 对方接听 → 回 App 点"接到了"。
  - 预期：结果卡四项全 ✓（按时响铃、锁屏弹出测试页、自动拨号已接通、对方确认接到），第二行显示"开启凭据有效"。
  - 记录：任何一项 ✗ 就截图结果卡，并附上触发延迟秒数。

## B. 首页向导与权限

- [ ] **B1** 卸载重装后打开：显示说明卡和 ①②③ 三步，主按钮是"选择紧急联系人"，没有灰色按钮。
- [ ] **B2** 设置联系人后 ① 打勾，主按钮变成"继续设置权限"。
- [ ] **B3** 在权限清单里点拨打电话 / 读取通话状态 / 通知的"去开启"：直接弹系统授权框，不是跳到应用详情页。
- [ ] **B4** 手动确认项逐个"去设置"能跳到对应的系统页面；勾选后计数增加；全部完成后 ② 打勾。
- [ ] **B5** 从首页进入权限清单，按返回键或顶栏返回，回到**首页**；从设置页进入，则回到设置页。
- [ ] **B6** 没有有效的 ≥30 分钟演练记录时，主按钮是"开始实机测试"，无法开启守护。A3 通过后主按钮变成"开启守护"，开启后通知栏**只有一条**状态通知。
- [ ] **B7** 设置联系人但不授予任何运行时权限，进入实机测试页：主按钮显示"先开启必要权限"且仍可点击；下方完整列出拨打电话、读取通话状态、发送短信、读取通话记录、通知。点击后进入权限清单，返回时仍回实机测试页，不会出现点击无反应。
- [ ] **B8** debug 包打开"开发快速阈值"但尚未完成权限：开关下方明确说明它不会自动开始测试、不会绕过权限，并显示"打开权限清单"；点击后进入权限清单。权限完成但守护尚未开启时，说明文字明确提示"当前守护未开启，不会开始计时"。

## C. 演练页行为

- [ ] **C1** 等待时长有 1 分钟 / 10 分钟 / 30 分钟 / 1 小时 / 2 小时五档，默认 30 分钟；选不足 30 分钟的档位会提示"快速检查，不计入开启条件"。
- [ ] **C2** 1 分钟演练完整走一遍：响铃 → 锁屏上弹出测试页（只有"停止测试"按钮）→ 自动拨号 → 回答问题 → 结果卡分两行显示"上次测试"和"开启凭据"。
- [ ] **C3** 锁屏等待期间提前解锁 → 结果为"中止"（不算失败）。
- [ ] **C4** 在演练页或响铃通知上点"停止测试" → 结果为"中止"，响铃和通知立即消失。

## D. 开启守护之后

- [ ] **D1** 开启后做一次 1 分钟演练，或做到一半停止 → 首页**没有**红色异常卡，状态通知仍是"守护中"；结果卡**不会**提示"开启守护前还需要 30 分钟测试"。
- [ ] **D2** 开启后故意做一次失败的演练（最简单的办法：拨号后回答"没接到"）→ 首页立即出现异常卡，通知变成"守护可能失效，请打开查看"，**守护仍在运行**；再做一次 30 分钟演练通过后恢复正常。
- [ ] **D3** 在设置里更换紧急联系人 → 提示需要重新测试，守护仍在运行，通知栏仍然只有一条状态通知。
- [ ] **D4** 开启后做一次演练，演练结束后真实守护照常计时（运行状态卡正常、状态通知恢复为"守护中"）。

## F. 多位紧急联系人 + 轮流重拨 + 报警短信（提交 caf8626 … f0f41d6）

需要 2–3 个安全号码（自己的其他手机或事先告知的人）。每条"记录"都要：截图 + 守护记录页相关行 + 各联系人手机上收到的短信截图 / 通话记录截图。

- [ ] **F1 升级安装迁移**
  - 操作：在旧版本已设置 1 位联系人（做过演练或已开启守护）的基础上覆盖安装新包，打开 App。
  - 预期：原联系人自动成为"第 1 位"；旧演练记录显示"演练规则已更新，请重新测试"；守护若已开启仍保持开启，首页出现异常卡提示重新测试。
  - 记录：首页与设置页截图、结果卡提示行。

- [ ] **F2 新增必需权限**
  - 操作：权限清单里查看"发送短信"与"读取通话记录"两项，分别点"去开启"。
  - 预期：两项都是必需项（非可选）；点击直接弹系统授权框；拒绝任一项后不能开始演练、不能开启守护。
  - 记录：权限清单截图、授权弹窗截图。

- [ ] **F3 联系人列表编辑**
  - 操作：设置页联系人卡：添加 3 位后再试添加；重复添加同一号码；只剩 1 位时看删除按钮；上移/下移调顺序；增删/改号码/调序后看演练凭据；只改名再看。
  - 预期：满 3 位显示"最多 3 位"无法再添加；重复号码被拒"该号码已在列表中"；只剩 1 位时无删除；顺序变化后凭据失效提示重新测试，只改名不失效。
  - 记录：联系人卡截图、凭据状态行截图。

- [ ] **F4 两位联系人的 30 分钟演练通过**
  - 操作：设 2 位安全号码，做 30 分钟完整演练：锁屏别动 → 到点响铃+测试页 → 等自动执行 → 每位收到"【守护侠·测试】"短信、按顺序各响一次电话并接听 → 回 App 逐位回答（短信/电话两题）。
  - 预期：结果"通过"，结果卡每位四项全 ✓，"开启凭据有效"。
  - 记录：结果卡截图 + 两部手机各自收到的短信与通话记录。

- [ ] **F5 演练故意失败（第 2 位不接）**
  - 操作：同 F4，但第 2 位的电话不接。
  - 预期：结果"未通过"，原因写明"<第 2 位姓名>：电话未接通…"；第 1 位四项仍全 ✓。
  - 记录：结果卡截图（含逐位小节）。

- [ ] **F6 真实报警·接通即停**
  - 操作：debug 包开"开发快速阈值"，策略为默认"接通即停"；锁屏等报警触发，第 1 位接听。
  - 预期：所有人先收到紧急短信（含"接通后若没人说话…请立即上门"），之后才响第 1 位电话；第 1 位接听后其他人不再被拨打；所有人收到"已由 X 接听"结果短信。
  - 记录：短信/通话时间顺序（短信先于电话）、两部手机截图。

- [ ] **F7 真实报警·继续拨打所有联系人**
  - 操作：设置页把策略切到"继续拨打所有联系人"，重走 F6。
  - 预期：第 1 位接听后仍拨第 2 位；全部拨完后所有人收到汇总短信。
  - 记录：两部手机通话记录与短信。

- [ ] **F8 无人接听跑满两轮**
  - 操作：所有人都不接电话，观察完整两轮。
  - 预期：约 3 分钟后从第 1 位开始第 2 轮；第 2 轮仍无人接则收尾，所有人收到"多次拨打均无人接听"；过程中首页报警卡显示"第 X / 2 轮"与每位状态（正在拨打/未接通/等待拨打）。
  - 记录：报警卡各阶段截图、两部手机通话记录、结果短信。

- [ ] **F9 报警中解除**
  - 操作：拨号途中（或轮间等待时）解锁手机点"我没事"。
  - 预期：不再拨打后续联系人；所有人收到"已解除"短信；首页回到守护中。
  - 记录：短信与首页截图。

- [ ] **F10 杀进程续拨**
  - 操作：序列进行中（例如轮间等待时）在最近任务里把守护侠划掉（不是强行停止）。
  - 预期：到点仍开始第 2 轮；没有重复收到紧急短信；已判定的那通没有被重拨。
  - 记录：两部手机收到的短信/来电次数 + 事件日志。

- [ ] **F11 自拨号不算使用**
  - 操作：观察 F6–F8 中拨出电话接通/挂断后首页状态。
  - 预期：拨号与通话本身不会被视为"有人使用手机"而解除报警（首页仍是报警中/已报警）。
  - 记录：首页截图、事件日志。

- [ ] **F12 报警期间不发平安短信**
  - 操作：开启平安短信，把时间调到报警状态仍在（已报警未解除）的时刻；之后恢复守护中等下一天。
  - 预期：已报警时刻到点不发"一切正常"平安短信；解除回守护中后次日正常发给所有联系人。
  - 记录：联系人手机短信列表截图。

- [ ] **F13 事件日志**
  - 操作：F4–F10 任一场景后看守护记录页。
  - 预期：所有号码打码（138****0000 形式）；可见"短信回执 ok=true"、"通话记录 result=ANSWERED/NOT_ANSWERED"等关键行。
  - 记录：记录页截图。
